도입 판단: effort 를 적고 옮긴다

Opus 5 에서 옮긴다. 다만 요청마다 effort 를 명시하고, 옮긴 뒤 같은 effort 로 비용을 다시 잰다. 원문의 40% 절감은 Opus 5 high 와 Opus 5.5 medium 을 견준 값이라 effort 가 한 단계 내려간 몫이 섞여 있다.

상황판단근거
effort 를 high 이하로 고정해 돌린다adopt같은 effort 에서 태스크당 비용이 여섯 벤치마크 모두 32~86% 내리고 점수는 오른다
max 로 돌린다assessCursorBench +12%, GDPval +32%, AutomationBench +8% 로 Opus 5 보다 비싸진다. 자기 워크로드에서 재고 정한다
thinking disabled, tool_choice 강제, computer_20251124, 대화 앞부분 수정 중 하나를 쓴다고친 뒤 adopt넷 다 400 이다. 04~07장의 diff 대로 고치면 된다

  • $4 · $20입력과 출력, 1M 토큰당. Opus 5 의 $5 · $25 에서 20% 인하
  • $0.20캐시 읽기. $0.50 에서 60% 인하로 가장 큰 항목이다
  • mediumeffort 를 적지 않은 요청의 기본값. Opus 5 는 high 였다

되돌리기는 모델 ID 를 바꾸면 끝난다. Opus 5 는 legacy 로 남고 Opus 5.5 의 thinking 블록만 읽지 못하므로 되돌린 턴의 reasoning 은 잃는다.

첨언: 원문, 계산, 되돌리기 시한

whats-new 「Behavior differences」: “The default effort is medium. A request that omits effort runs at medium; on Claude Opus 5 it ran at high.” 같은 문서: “At the same effort setting the model tends to think more per turn than Claude Opus 5, most of all at xhigh and max.”

절감률은 원문 차트의 점에서 1 − (Opus 5.5 비용 / Opus 5 비용) 으로 계산했고 원문에는 같은 effort 끼리의 비교가 없다. high: Terminal-Bench 4.0 $3.88 대 $10.64 (−64%), FrontierCode $1.09 대 $7.62 (−86%), CursorBench $3.97 대 $9.00 (−56%), GDPval $1.54 대 $3.03 (−49%), AutomationBench $0.70 대 $1.03 (−32%), WANDR $16.88 대 $43.49 (−61%). max: −29%, −50%, +12%, +32%, +8%, −38% 같은 순서다.
